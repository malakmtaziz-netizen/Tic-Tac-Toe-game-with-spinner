 # Tic-Tac-Toe with Bursa Trivia & Lucky Spinner

Tic-Tac-Toe with Bursa Trivia & Lucky Spinner is an interactive Java-based desktop game that combines the classic Tic-Tac-Toe experience with trivia questions about Bursa and a fun pre-game lucky wheel.

The game features a graphical user interface developed using Java Swing and AWT, allowing players to interact with the board and game controls visually. Before starting the game, players can spin a Lucky Pre-Game Spinner to receive special rewards, including playing first, skipping a question, or playing without questions.

During the game, players can answer trivia questions related to Bursa, with a database containing 73 questions and answers covering the city's history, culture, landmarks, food, and famous locations.

The game also includes two computer-player modes. The Random AI selects available moves randomly, while the Smart AI uses game-state analysis to identify winning opportunities, block the player's potential wins, and select strategically preferred moves.

The project demonstrates practical applications of Object-Oriented Programming, event handling, GUI development, randomization, game logic, and basic AI decision-making in Java.
 
The project was developed collaboratively with my classmate Jana Abdelaziz, combining our efforts in implementing the game logic, user interface, AI features, and overall game experience.
